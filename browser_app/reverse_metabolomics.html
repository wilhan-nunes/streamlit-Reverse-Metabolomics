Reverse Metabolomics

Search MS/MS spectra (USIs) across public metabolomics data with FASST, then see which body parts, diseases and organisms they turn up in, using ReDU sample metadata. All analysis runs in your browser: your ReDU file never leaves your machine, and only the USIs and search settings are sent to the FASST search service.

How to use this tool

  1. Load ReDU metadata (step 1): drop the dump from redu.gnps2.org/dump. It's saved in this browser, so you only do this once.
  2. Enter USIs (step 2): type or paste Universal Spectrum Identifiers with compound names, import a CSV/TSV, or load an example set.
  3. Set FASST parameters if the defaults don't suit you.
  4. Run the FASST search. Each USI is searched against the chosen index.
  5. Adjust the analysis: choose the organism and the ReDU variable (body part, disease, sex or age), and exclude values you don't want.
  6. Download tables as CSV and figures as SVG.

Available visualizations

  • Raw counts: spectral match counts.
  • Log-transformed counts: log2(count + 1), which makes low-abundance features easier to see.
  • ReDU-normalized counts: counts normalized by how many ReDU samples exist for each category.
  • A query with a single compound gets a bar chart instead of a heatmap.

Tips

  • Use the clustering options to reveal patterns.
  • The page URL keeps your query and settings, so Copy shareable link lets others reproduce them.

This app is part of the GNPS downstream analysis ecosystem known as MetaboApps. Check out other tools.
